# Contributing Guidelines

Thank you for exploring this project! We maintain strict open-source engineering standards to guide both junior and senior developers.

## Development Workflow

1. **Fork the Project:** Clone a copy of this repository into your personal GitHub account profile workspace.
2. **Setup Local Environment:** Create a separate feature branch tracking your work (`git checkout -b feature/your-feature-name`).
3. **Write Consistent Logic:** Follow standard clean code rules. Ensure files stay completely decoupled within MVC modules.
4. **Execute Verification Tests:** Before proposing changes, execute the local automation validation array (`npm test`) to guarantee no routes break.
5. **Open a Pull Request:** Explain your technical solution layout clearly within your code documentation submission dashboard.
